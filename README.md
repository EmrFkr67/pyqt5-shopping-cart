# PyQt5 Shopping Cart

A desktop shopping cart management application built with **Python** and **PyQt5**.

## Features
- Add and remove items with quantity and unit price validation
- Special offer item highlighting (`coffee`, `apple`, `cereal`, `cheese`, `pasta`)
- Coupon code discount engine (`WELCOME10`, `SAVE20`, `MEGA25`) with single-use coupon tracking
- Live cart view, itemized summary, and total price calculation in a PyQt5 GUI

## How to Run
```bash
pip install -r requirements.txt
python main.py
```
